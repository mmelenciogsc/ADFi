# Local ADFication pipeline

The immutable source and all private evidence remain under the user's Windows project directory. Every phase consumes persisted outputs from earlier phases, writes new outputs atomically, validates them, records their hashes/checkpoint, disposes heavyweight resources, and confirms current free resources before the next heavyweight phase.

1. Source intake records the exact rights attestation, user/project/time/source SHA-256 and ffprobe stream data; unsupported paths, remote URIs and insufficient working disk fail closed.
2. Audio preparation creates analysis-only mono 16 kHz audio, level/silence measurements and bounded 30-second chunks with one-second overlap. Whisper processes chunks sequentially; results are persisted immediately and merged by absolute time. On resume, each valid saved chunk is restored and only missing/corrupt chunks are transcribed. Dialogue overrides apparent silence, while active non-dialogue sound remains protected.
3. Visual indexing uses inexpensive OpenCV metrics after Whisper has explicitly unloaded. It detects scene boundaries, selects a hardware-bounded temporal sequence, suppresses near-duplicates, saves timestamped frame evidence and relates each scene to transcript and narration-window IDs.
4. Face continuity uses pinned OpenCV Zoo YuNet/SFace detection and embeddings only to cluster a recurring person within the project. Ambiguous matches create a new anonymous entity rather than merging people. It never identifies a person from appearance. Names require separate explicit evidence and an establishment time.
5. OCR sends only deterministically text-likely frames to Qwen first, validates its evidence IDs and normalized crop bounds, unloads Qwen, and only then invokes Tesseract on focused crops when exact characters matter or confidence is low. Competing readings remain explicit instead of selecting plausible text.
6. Qwen visual analysis processes one bounded scene package at a time with nearby transcript, time-valid anonymous entities, face boxes, and reconciled OCR. Every material observation must cite a supplied frame evidence ID, results persist per scene, and Qwen unloads after the stage.
7. AD necessity protects dialogue and meaningful sound, prioritizes significant information absent from audio and creates no interval merely because a cut occurred.
8. Drafting uses only verified facts and time-valid names. A 180-WPM plan leaves breathing room; exact Piper output is then measured. At most three semantics-preserving rewrites are attempted, after which review is mandatory.
9. Preview and review operate on committed project versions. Only `ApplyProjectMutation` persists a proposed edit; undo/restore append compensating versions.
10. Final validation blocks missing evidence/audio, overlaps, overruns and media mismatches. Rendering mixes narration smoothly and stream-copies a compatible video stream whenever possible.
11. Publication is optional and upload-only. The user confirms the OAuth-authenticated channel and visibility. DISCOVER activation is a later independent choice and uses the official YouTube player.

The `prompts/semantic-tools.json` contract is the authoritative allow-list for model-planned operations. It contains no arbitrary command tool.

The Windows **Run or resume audio and scene analysis** action currently composes Phases 1 and 2 through `SequentialPipelineCoordinator`. Before running, it rechecks current free RAM/VRAM and may downshift model/frame bounds, verifies the source SHA-256 has not changed, and rechecks temporary disk space. A completed phase is skipped only when its manifest still matches the checkpoint hash; corrupt or missing output is rebuilt. The UI announces restored/transcribed chunk counts and the transition into scene indexing without loading Whisper and OpenCV concurrently.

The following **Continue with characters, text, and scene understanding** action composes Phases 3–5 with the same verified-checkpoint rule. Face models are disposed before Qwen starts. Visual-text Qwen work unloads before Tesseract verification, and a fresh bounded Qwen runtime handles final scene semantics. No internet identity search or appearance-derived name is available in this workflow.
