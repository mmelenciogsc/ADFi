# Implementation status

Status date: 2026-10-02. This file distinguishes executable, tested code from integration work that still needs external credentials, licensed model assets, or deployment access.

## Implemented and verified on Windows 11

- The canonical `D:\ADFi` Git monorepo builds under .NET SDK 10.0.401 with warnings as errors.
- The WPF composition root exposes exactly two top-level destinations, MY ADFi and DISCOVER, using native UI Automation controls. It now implements accessible registration/login/recovery forms, DPAPI-protected session restore, fail-closed server entitlement refresh, Creator-gated local source selection, cancellable Phase 0 intake, local project/checkpoint discovery, review-state loading, anonymous DISCOVER refresh, default-browser project opening, deterministic tab order and explicit UI Automation live-region events. Architecture tests enforce these boundaries and the exact rights-attestation text.
- There are exactly two paid plan definitions: Community at USD $2/month and Creator at USD $9/month. Creation and conversational-editing entitlements are Creator-only in domain policy and server-derived subscription results.
- Source intake accepts existing supported local video files only, requires the versioned rights attestation, hashes the untouched source, runs ffprobe, estimates temporary space, refuses insufficient space, and atomically persists source metadata.
- Phase 1 creates a normalized analysis-only mono 16 kHz stream, characterizes levels/silence, creates bounded overlapping chunks, persists each transcription chunk, deterministically merges overlap, and combines transcript dialogue with silence and meaningful-source-sound intervals. Its official OpenAI Whisper adapter keeps one hardware-selected model in a bounded Python worker, transcribes chunks sequentially with word timestamps, maps results to absolute source time, and explicitly unloads before later heavyweight stages.
- Phase 2 uses bounded OpenCV sampling, deterministic cut/text/motion metrics, temporal keyframe selection, near-duplicate suppression, actual JPEG evidence extraction, transcript/window correlation, and an atomic visual-index manifest.
- Phase 3 has project-local YuNet/SFace face detection/embedding and conservative continuity matching. It cannot perform internet or real-world identity lookup; names become usable only from explicit time-stamped evidence.
- Phase 4 has evidence-preserving VLM/Tesseract OCR reconciliation that retains conflicting readings and requests more evidence rather than selecting plausible fiction.
- Phase 5 sequentially sends only bounded indexed frames, nearby transcript and time-valid established entities to Qwen through `ILocalModelRuntime`; every response is schema/evidence checked, persisted by scene, and followed by model unload.
- Phases 6–8 include AD-necessity scoring, quiet-window selection, an evidence-bound writer, 180-WPM planning, spoiler/dialogue/evidence checks, five reviewed Piper voice choices, per-segment cached synthesis, actual WAV measurement, and at most three shortening attempts before required review. Speech is never silently time-compressed.
- Phase 9 creates a full draft by stream-copying compatible source video with temporary reviewed audio, can create an exact short focus preview, persists `REVIEW_IN_PROGRESS`, and checkpoints the artifact for crash recovery.
- Phase 12 validates media/evidence/narration invariants, builds a narration track, uses smooth source-audio ducking and limiting, stream-copies compatible H.264/HEVC/AV1 video when possible, and never overwrites the source.
- Pipeline phase starts, completions and failures are checkpointed atomically with concise screenreader progress announcements; restart skips only verified completed phases. Project edits are append-only, use optimistic version checks, and undo/checkpoint restoration create compensating versions.
- Nontrivial conversation requests pass through a deterministic intent classifier and schema-validated local Planner. Tool names must exist in the versioned allow-list, and task execution remains strictly sequential with result persistence after every atomic task.
- Creator activation profiling records architecture, CPU features/threads, system/free RAM, NVIDIA model/total/free VRAM when available, acceleration, disk type/free space and bounded FFmpeg throughput. It selects from currently free RAM/VRAM before one bounded Ollama measurement, persists the result per Windows account, and immediately unloads the model. The accessible desktop runs this automatically after first verified Creator activation and offers an explicit recheck.
- Ollama is behind `ILocalModelRuntime`; the balanced tier is the installed official `qwen3-vl:4b-instruct` package, with replaceable constrained/large tiers and no schema changes.
- Five Piper voices with noncommercial restrictions excluded are versioned in the voice catalog. Piper itself and every voice model remain separately licensed dependencies.
- Google installed-app OAuth request generation uses state and PKCE; token exchange/refresh uses the required upload/channel-read scopes; refresh tokens persist through `IProtectedSecretStore`, whose Windows implementation uses current-user DPAPI. Publication confirms the exact channel and performs upload-only resumable `videos.insert` from a finalized local MP4. Status refresh fails closed when a video disappears, is rejected, or cannot be embedded while preserving separately established ADFi rights states.
- PayPal sandbox/production REST boundaries create subscriptions from configured provider plan IDs, verify webhook signatures through PayPal, deduplicate event IDs, retain and replay events delivered before the subscription row exists, apply timestamp-monotonic subscription status, and submit payouts with stable batch/item IDs. Secrets are server configuration only.
- Account registration, email verification, PBKDF2-SHA512 password hashing, opaque hashed bearer sessions, session rotation, one-use 30-minute recovery tokens and all-session revocation after reset are implemented.
- PostgreSQL migrations cover the normalized product, collaboration, moderation, publication, referral, rights, ledger, payout and feature-configuration domains. Economic allocation enforces the fixed 70/30 top-level policy and only qualified ADFi-native events.
- The anonymous API exposes liveness, dependency-aware readiness, plan and PostgreSQL-backed DISCOVER endpoints. Only records explicitly marked playable and discoverable in eligible publication states are returned; the public HTML surface has landmarks, a skip link, the official privacy-enhanced YouTube player and ADFi canonical sharing rather than bare YouTube sharing. Missing database/public-base configuration fails clearly instead of presenting a misleading empty catalog.
- Ubuntu deployment stages an immutable release, runs migrations before switching the current symlink, enables/restarts the hardened systemd unit, checks readiness and restores the prior release on failure. The current build is deployed on `BLACKOUT` behind nginx TLS with all three PostgreSQL migrations applied and live/readiness checks healthy. The exact LAN development certificate is trusted in this Windows user's certificate store and strict HTTPS succeeds without a validation bypass; production still requires public trust.

The current automated suite contains 131 passing tests: 113 core/integration-policy tests, 9 API tests and 9 architecture tests. The media integration test generates a real local H.264/AAC fixture, runs ffprobe, Phase 0, audio preparation, OpenCV visual indexing, source-preserving final rendering, full-draft preview assembly and an exact short focus preview.

Network calls are implemented and isolated behind tested provider boundaries, but no sandbox subscription/payout or live YouTube upload has been executed.
