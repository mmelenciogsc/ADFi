# Implementation status

Status date: 2026-10-02. This file distinguishes executable, tested code from integration work that still needs external credentials, licensed model assets, or deployment access.

## Implemented and verified on Windows 11

- The canonical `D:\ADFi` Git monorepo builds under .NET SDK 10.0.401 with warnings as errors.
- The WPF composition root exposes exactly two top-level destinations, MY ADFi and DISCOVER, using native UI Automation controls. It now implements accessible registration/login/recovery forms, DPAPI-protected session restore, fail-closed server entitlement refresh, Creator-gated local source selection, cancellable Phase 0 intake, native resumable actions through Phase 9, an accessible five-voice Piper selector/preview, a keyboard-operated full-draft/focused-preview player, local project/checkpoint discovery, review-state loading, anonymous DISCOVER refresh, default-browser project opening, deterministic tab order and explicit UI Automation live-region events. Architecture tests enforce these boundaries and the exact rights-attestation text.
- MY ADFi now opens a native Accessible Interactive Video Viewer for both verified paid tiers. It provides explicit local-file and pasted-YouTube choices, WPF local playback, official WebView2 YouTube IFrame playback, `Alt+Q` plus a real Ask button, pause confirmation/exact checkpoint, deterministic question→DICTATE focus order, Enter submission, one processing/ready announcement, selectable answer/history, explicit exact-time resume, Escape/close without resume, local context replay and user-deletable textual history. DISCOVER selections can open directly in the same viewer.
- Portable moment-VQA contracts, intent/minimum-evidence classification, tier/provider/read-only policy and request validation are executable. Local FFmpeg evidence is limited, downscaled and private; ADFi publications and arbitrary matching YouTube IDs resolve server-stored scene/OCR/entity/AD/dialogue evidence first. Session/request evidence cleanup covers error, resume, seek, source change, close and process exit. Serialized models exclude local/evidence paths.
- A bounded arbitrary-YouTube player-region provider enforces one user-triggered capture per request and has no seek/iteration/export API. Its PostgreSQL/server flag defaults off pending compliance clearance; official playback and Ask remain available. A separate ChatGPT plan-usage flag defaults off pending OpenAI approval for ADFi as a paid app.
- ChatGPT profile lifecycle uses system-browser OAuth, random loopback callback, state/nonce/PKCE, dynamic-client continuity, JWKS/issuer/audience/expiry/nonce ID-token validation, current-user DPAPI vault persistence, serialized refresh rotation, profile selection and revocation/local disconnect. Native screenreader-named Continue, profile, Manage usage and Disconnect controls are wired to the real VQA provider. Transport lists account-available models and uses only the public Responses API with OAuth bearer authorization, `store: false`, `stream: true`, completion-only result release and documented limit/reauthorization errors. Visual queries deterministically refuse to guess when direct evidence is unavailable. The entire flow remains server-gated until external provider approval and real credential acceptance testing.
- DISCOVER viewers can turn a selected answer into an editable, timestamped accessibility feedback draft; explicit submission creates only a `PENDING` feedback entry. VQA/viewing never creates an earnings event.
- There are exactly two paid plan definitions: Community at USD $2/month and Creator at USD $9/month. Creation and conversational-editing entitlements are Creator-only in domain policy and server-derived subscription results.
- Source intake accepts existing supported local video files only, requires the versioned rights attestation, hashes the untouched source, runs ffprobe, estimates temporary space, refuses insufficient space, and atomically persists source metadata.
- Phase 1 creates a normalized analysis-only mono 16 kHz stream, characterizes levels/silence, creates bounded overlapping chunks, persists each transcription chunk, deterministically merges overlap, and combines transcript dialogue with silence and meaningful-source-sound intervals. Its official OpenAI Whisper adapter keeps one hardware-selected model in a bounded Python worker, transcribes chunks sequentially with word timestamps, maps results to absolute source time, and explicitly unloads before later heavyweight stages.
- Phase 2 uses bounded OpenCV sampling, deterministic cut/text/motion metrics, temporal keyframe selection, near-duplicate suppression, actual JPEG evidence extraction, transcript/window correlation, and an atomic visual-index manifest.
- Phases 1–2 are now composed into a runnable Creator workflow. Each run rechecks free RAM/VRAM, downshifts hardware bounds when needed, verifies the immutable source hash and disk headroom, restores valid per-chunk transcripts, explicitly unloads Whisper before OpenCV, hashes final manifests and rebuilds a supposedly complete stage if its checkpoint artifact is missing or corrupt.
- Phase 3 has a runnable project-local YuNet/SFace indexer with conservative continuity matching, anonymous entity manifests and per-frame progress. Ambiguous matches remain separate. It cannot perform internet or real-world identity lookup; names become usable only from explicit time-stamped evidence.
- Phase 4 has a runnable Qwen-first visual-text locator that is restricted to deterministically text-likely frames, validates cited frames/crop bounds, unloads Qwen, then selectively runs focused Tesseract verification. Evidence-preserving reconciliation retains conflicting readings rather than selecting plausible fiction.
- Phase 5 sequentially sends only bounded indexed frames, nearby transcript, reconciled OCR, project-local face continuity and time-valid established entities to Qwen through `ILocalModelRuntime`; every response is schema/evidence checked, persisted by scene, aggregated in a hashed completion manifest and followed by model unload.
- Phases 6–8 are now composed into a runnable Creator workflow. It converts only evidence-cited observations into time-valid facts, waits until the latest cited/spoiler-safe visual time, selects quiet non-dialogue windows, resumes validated per-segment drafts, preserves prompt provenance, generates Piper audio sequentially, measures actual WAV duration and permits at most three evidence-preserving shortening attempts before required review. Narration assets carry SHA-256 validation; corrupt caches regenerate; completed results append an initial versioned review draft without overwriting existing reviewed state. Speech is never silently time-compressed.
- Phase 9 is now runnable from MY ADFi. It validates source, scene evidence, narration timing, project-relative paths and narration hashes before creating a full draft. Compatible video is stream-copied, its typed `REVIEW_IN_PROGRESS` manifest and full/focus artifacts are independently hashed, valid full drafts resume without rerendering, changed focus ranges rebuild only the short focus clip and corrupt previews regenerate. Native screenreader-named Play, Pause and Play around selected description controls expose the result.
- Phase 12 validates media/evidence/narration invariants, builds a narration track, uses smooth source-audio ducking and limiting, stream-copies compatible H.264/HEVC/AV1 video when possible, and never overwrites the source.
- Pipeline phase starts, completions and failures are checkpointed atomically with concise screenreader progress announcements; restart skips only a contiguous dependency chain of verified completed phases, so an invalid earlier artifact forces dependent work to rerun. Project edits are append-only, use optimistic version checks, and undo/checkpoint restoration create compensating versions.
- Nontrivial conversation requests pass through a deterministic intent classifier and schema-validated local Planner. Tool names must exist in the versioned allow-list, and task execution remains strictly sequential with result persistence after every atomic task.
- Creator activation profiling records architecture, CPU features/threads, system/free RAM, NVIDIA model/total/free VRAM when available, acceleration, disk type/free space and bounded FFmpeg throughput. It selects from currently free RAM/VRAM before one bounded Ollama measurement, persists the result per Windows account, and immediately unloads the model. The accessible desktop runs this automatically after first verified Creator activation and offers an explicit recheck.
- Ollama is behind `ILocalModelRuntime`; the balanced tier is the installed official `qwen3-vl:4b-instruct` package, with replaceable constrained/large tiers and no schema changes.
- Five Piper voices with noncommercial restrictions excluded are versioned in the voice catalog. Piper itself and every voice model remain separately licensed dependencies.
- Google installed-app OAuth request generation uses state and PKCE; token exchange/refresh uses the required upload/channel-read scopes; refresh tokens persist through `IProtectedSecretStore`, whose Windows implementation uses current-user DPAPI. Publication confirms the exact channel and performs upload-only resumable `videos.insert` from a finalized local MP4. Status refresh fails closed when a video disappears, is rejected, or cannot be embedded while preserving separately established ADFi rights states.
- PayPal sandbox/production REST boundaries create subscriptions from configured provider plan IDs, verify webhook signatures through PayPal, deduplicate event IDs, retain and replay events delivered before the subscription row exists, apply timestamp-monotonic subscription status, and submit payouts with stable batch/item IDs. Secrets are server configuration only.
- Account registration, email verification, PBKDF2-SHA512 password hashing, opaque hashed bearer sessions, session rotation, one-use 30-minute recovery tokens and all-session revocation after reset are implemented.
- PostgreSQL migrations cover the normalized product, collaboration, moderation, publication, referral, rights, ledger, payout and feature-configuration domains. Economic allocation enforces the fixed 70/30 top-level policy and only qualified ADFi-native events.
- The anonymous API exposes liveness, dependency-aware readiness, plan and PostgreSQL-backed DISCOVER endpoints. Only records explicitly marked playable and discoverable in eligible publication states are returned; the public HTML surface has landmarks, a skip link, the official privacy-enhanced YouTube player and ADFi canonical sharing rather than bare YouTube sharing. Missing database/public-base configuration fails clearly instead of presenting a misleading empty catalog.
- Ubuntu deployment stages an immutable release, runs migrations before switching the current symlink, enables/restarts the hardened systemd unit, checks readiness and restores the prior release on failure. Viewer release `20261001T212925Z` is deployed on `BLACKOUT`; migration 0004 completed before activation, systemd is active, strict HTTPS readiness is healthy, and the live feature endpoint confirms both compliance switches are false. The exact LAN development certificate is trusted in this Windows user's certificate store without a validation bypass; production still requires public trust.

The current automated suite contains 182 passing tests: 160 core/integration-policy tests, 10 API tests and 12 architecture tests. Media integration tests generate real local H.264/AAC fixtures and cover ffprobe, Phase 0, resumable Phase 1 transcription, Phase 2 OpenCV indexing, corrupt-checkpoint recovery, bounded ephemeral viewer-frame extraction and cleanup, anonymous continuity, Qwen-first focused OCR reconciliation, evidence-cited scene analysis, time-valid AD opportunity selection, resumable drafting, measured narration with cache-corruption recovery, source-preserving final rendering, content-addressed full-draft restore, focus-only preview regeneration and corrupt-preview recovery. The installed pinned OpenCV Zoo models also pass a maintained-API load smoke test on this Windows machine.
